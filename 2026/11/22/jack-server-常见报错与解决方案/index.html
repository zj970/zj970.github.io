一、关于 jack-server

Jack （Java Android Compiler Kit）是 Android 的一个工具链，包含：

  • Jack：编译 Java 代码到 Dalvik 字节码
  • Jill：将 Java 库转换为 Jack 库格式
  • Jack server：一个常驻后台服务，用于缓存和加速编译过程

从 AOSP Android N(7.0) 首次引入，AOSP Android P(9.0) 正式弃用；

二、常见问题

日志文件目录： ~/.jack-server/logs

工具目录：$AOSP/prebuilts/sdk/tools/jack-admin

2.1、端口占用

Communication error with Jack server (58), try 'jack-diagnose' or see Jack server log
Failed to contact Jack server: Problem reading /home/user3/.jack-server/client.pem. Try 'jack-diagnose'

一般是编译突然中止(多用户编译占用端口导致)，使用 netstat -ap | grep 8076 查看端口号是否占用;
若占用需修改 ~/.jack-server/config.properties 以及 ~/.jack-settings 默认内容如下：

cat ~/.jack-settings 

# Server settings
SERVER_HOST=localhost
SERVER_PORT_SERVICE=8076
SERVER_PORT_ADMIN=8077
# Internal, do not touch
SETTING_VERSION=4

cat ~/.jack-server/config.properties 

#Thu Oct 16 15:35:31 CST 2025
jack.server.idle=180
jack.server.max-service.by-mem=1\=2147483648\:2\=3221225472\:3\=4294967296
jack.server.shutdown=21600
jack.server.time-out=7200
jack.server.max-jars-size=104857600
jack.server.service.port=8076
jack.server.admin.port=8077
jack.server.config.version=4
jack.server.max-service=4
jack.server.deep-idle=900

重新配置用户端口(1024-49151) 部分特殊端口可能被应用占用，比如 3306、3389、8080、8888 等，建议使用 netstat -ap | grep [端口号] 查看端口号是否占用，例如修改

配置 端口号
SERVER_PORT_SERVICE 8066
jack.server.service.port
SERVER_PORT_ADMIN 8067
jack.server.admin.port
注意：两组值需相互一致

2.4、常用命令

# 清除所有配置(可选)
rm -rf ~/.jack-server
rm -rf ~/.jack-settings
rm -rf ~/.jack

# 注意：如果是卸载服务、清除配置之后，第一点配置的端口就会默认为 8076
# 工具目录
cd AOSP/prebuilts/sdk/tools

# 强制结束服务
./jack-admin kill-server

# 启动服务
./jack-admin start-server

# 安装服务
./jack-admin install-server jack-launcher.jar jack-server-4.11.ALPHA.jar

# 卸载服务
./jack-admin uninstall-server

# 日志导出
./jack-admin dump-report

# 日志目录
ls ~/.jack-server/logs

三、总结

jack-server 是低版本编译才会有，高版本使用 Soong + R8 替代
